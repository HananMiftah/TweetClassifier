# Tweet Sentiment Classifier — Frontend

This is the **frontend** of the Tweet Sentiment Classifier Web Application.  
The application allows users to upload tweet datasets as csv file and get a **sentiment prediction** (Positive, Negative, or Neutral) using a machine learning model hosted in the backend.

🔗 **Live Demo:** https://tweet-classifier-two.vercel.app  
🔗 **Backend Repo:** https://github.com/HananMiftah/backend

---

## 🚀 Features

- 🟦 Built with **React.js**
- 🎨 Styled using **Tailwind CSS**
- 🌐 Connects to a Django REST API
- ⚡ Fast and responsive UI
- 📊 Displays sentiment predictions instantly
- 🔁 Includes UI for sending requests to the ML model
